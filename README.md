# منيو لقمة ابن الشيخ

منيو ويب عربي متجاوب مع الموبايل: أقسام وبحث، وتخصيص كل صنف (الحجم/النوع، الإضافات، اختيار السلطة، الكمية، ملاحظات)، وسلة طلب تُرسل عبر واتساب.

## الملفات
- `index.html`: هيكل الصفحة.  `style.css`: التصميم والألوان.  `app.js`: البحث والسلة والإرسال.
- `menu-data.js`: **كل الأسعار والأصناف والبيانات** (الهاتف، واتساب، العنوان).
- `logo.png` و`img/`: الشعار وصور الأقسام (مقصوصة من المنيو المطبوع، ويُفضّل استبدالها بصور أعلى جودة بنفس الأسماء).

## التعديل
افتح `menu-data.js`:
- غيّر السعر: عدّل الرقم في سطر الصنف. الأسعار بترتيب `labels` ويمكن كتابة `null` لو الحجم غير متاح.
- أضف صنفًا: أضف سطرًا `["الاسم", "وصف", السعر]` داخل القسم المناسب.
- `whatsappNumber`: بصيغة دولية بدون صفر (`201116502424`).

## النشر والتجربة
ارفع كل الملفات (مع مجلد `img`) على GitHub ثم Cloudflare Pages بنفس خطوات النشر المعتادة (Framework: None، بدون Build command). افتح `index.html` من الفولدر بعد فك الضغط، وليس من داخل الـzip.
ثم أنشئ QR Code من رابط الموقع وجرّبه على موبايل قبل الطباعة.

## ملاحظات
- ترتيب الأسعار والأصناف نُقل من صورة المنيو؛ راجعها قبل النشر.
- رسوم التوصيل غير مضمّنة في الإجمالي.
- حالة الطلب وبيانات العميل تُحفظ في متصفحه فقط.
